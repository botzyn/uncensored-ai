*(Note: Demo mode uses fallback responses. Deploy server for real AI.)*

## Quick Deploy to Vercel (Free)

```bash
# Install Vercel CLI
npm i -g vercel

# Login
vercel login

# Deploy (auto-detects Node.js API routes)
cd uncensored-ai
vercel --prod
```

Or deploy via web:
1. Go to https://vercel.com
2. Import `botzyn/uncensored-ai`
3. Add `GROQ_API` in Environment Variables
4. Deploy
